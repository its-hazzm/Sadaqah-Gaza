# تطبيق صدقة - Sadaqah App 📱

تطبيق إسلامي شامل صُمم ليكون صدقة جارية، يعمل بدون اتصال بالإنترنت (Offline).

## ✨ المميزات الرئيسية
* **القرآن الكريم كاملاً:** تلاوة مريحة بالرسم العثماني مع حفظ علامة التوقف.
* **السبحة الإلكترونية:** مسحوبة بعداد وتدعم الاهتزاز (Haptic Feedback).
* **الأذكار وحصن المسلم:** أذكار الصباح والمساء وأدعية يومية.
* **مواقيت الصلاة:** حساب أوقات الصلوات الخمس بدون إنترنت.

## 🛠 التقنيات المستخدمة
* **Framework:** React Native / Expo
* **Language:** JavaScript
